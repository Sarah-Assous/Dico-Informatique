# Dico.Informatique

**🔗 Live demo: [sarah-assous.github.io/Dico-Informatique](https://sarah-assous.github.io/Dico-Informatique/)**

An interactive **French glossary of computer science and tech vocabulary**: 278 terms in 15 themes, from programming languages and databases to cloud, cybersecurity, AI and job-search vocabulary.

I created it as a personal project to help French speakers (including me!) understand the words they hear in job interviews and at work in the tech industry. Each term comes with a simple definition, a real-life example and, when useful, a tip for interviews.

## ✨ Features
- **Instant search** while typing, accent-insensitive (`donnees` finds `données`)
- **Highlighting** of the searched words in the results
- **Smart sorting**: terms whose name matches the search appear first
- **Theme filters** (web, languages, databases, cloud & DevOps, networks, cybersecurity, AI…)
- **Light and dark mode**, following the system setting
- Responsive design, works on mobile

## 🛠️ Built with
- **HTML5**, **CSS3** (custom properties, flexbox, sticky header, media queries)
- **Vanilla JavaScript** (no framework): DOM rendering, event handling, text normalization with `String.normalize`, filtering and sorting
- Hosted with **GitHub Pages**

The page is a single `index.html` file, with the glossary data stored as a JavaScript object.

> This project was built with the help of AI tools, which I used to speed up development and to review the definitions.

## ▶️ Run locally
Just open `index.html` in any web browser.
